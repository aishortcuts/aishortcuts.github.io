How to create custom AI commands for your daily tasks

Open Settings → Commands → Add New…, give the command a name, write a system prompt that says how the AI should behave, and optionally set a keyboard shortcut. Your command then appears in the popup like the built-in ones.

Step by step

  1. Open the Command Manager. Open Settings → Commands and click Add New…
  2. Name it and write the prompt. Fill Command Name and System Prompt / Instruction. Describe the output you want and say “output only the result”.
  3. Optional settings. Set a Keyboard Shortcut, an icon, or an AI override (a different provider or model just for this command). Untick “Open in a separate pop-up window” to replace the selected text directly.
  4. Use it. Select text, press the hotkey and run your new command. Export your commands to back them up or share them.

Example 1: commit message

System prompt:

Write a git commit message in Conventional Commits format for the change described. Output only the message: a subject line of at most 72 characters, then a blank line and a short body if needed.

Real example: input

fixed bug where the settings window crashed when the user had no api key saved, now it shows an empty field instead. also added a unit test for it

AI response

fix(settings): prevent crash when no API key is saved

Handle missing API key by displaying an empty field instead of crashing.
Added a unit test to verify the fix.

Example 2: customer support reply

System prompt:

Write a polite, concise customer support reply in the same language as the customer's message. Acknowledge the problem, give the next step, and do not promise things you cannot guarantee.

Real example (Vietnamese): customer message

Chào shop, mình đặt đơn hàng cách đây 5 ngày mà vẫn chưa nhận được, mã đơn 12345. Mình cần gấp, shop kiểm tra giúp mình với.

AI response

Chào bạn, shop rất tiếc vì sự chậm trễ này và hiểu bạn đang cần đơn hàng gấp.

Shop đã tiếp nhận mã đơn 12345 và sẽ liên hệ ngay với bên vận chuyển để kiểm tra tình trạng đơn hàng. Shop sẽ cập nhật thông tin cho bạn ngay khi có phản hồi từ đơn vị vận chuyển nhé.

Cảm ơn bạn đã kiên nhẫn và thông cảm cho shop.

Tips

  • A good prompt states the role, the output format and what to avoid. Short and specific works best.
  • Give each command its own shortcut for the tasks you repeat all day.
  • Use the AI override to send private commands to a local model and the rest to a cloud model.

FAQ

How many commands can I create?

There is no fixed limit. You can reorder, edit, export and import them.

Can I share my commands?

Yes. Export them as a file and import the file on another computer.

Do custom commands work with every provider?

Yes. They use the default provider unless you set an override for the command.
