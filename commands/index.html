How to use

  1. 1

    Download the command file

    Click the Download button on any command card above to save its .json file to your computer.

  2. 2

    Open AI Shortcuts Settings

    Open AI Shortcuts, navigate to Settings → Commands, and click Import…

  3. 3

    Select the downloaded file

    Select the downloaded .json file. The command will instantly appear in your shortcuts menu and is ready to use.

Share your own command

Created a prompt that saves you time? Share it with the community! In AI Shortcuts, export your command from Settings → Commands, then open a pull request in our repository.

All community contributions are reviewed by maintainers before appearing in the gallery.
