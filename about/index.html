About AI Shortcuts

AI Shortcuts is a free, open-source, system-wide AI writing assistant for Windows, macOS and Linux. Select text in any app, press a hotkey, and proofread, rewrite or summarize it in place with the AI provider you choose.

Project

AI Shortcuts is maintained by Nam Trần and released under the GPL-3.0 license.

It is a fork of WritingTools by theJayTea, extended with a command manager, attachments, more AI providers and more interface languages.

Source code, releases and issues are on GitHub.

Platforms

Windows 10 or later (64-bit), Linux with an X11 session, and macOS 14 Sonoma or later. The default hotkey is Ctrl+Space on Windows and Linux, and Option+Space on macOS.

Privacy and data flow

Text is sent only to the AI provider you configure, and only when you run a command. The app has no telemetry or analytics. Use Ollama or MLX to keep everything on your device.

On macOS, API keys are stored in the Keychain. On Windows and Linux, provider keys are saved in the app settings file with light obfuscation (not encryption); per-command override keys use the operating system keyring when available. Details are in the security policy.
